VANGUARD pour Linux — comment le lancer
======================================
English: README.txt

Le programme : « vanguard », dans ce dossier. Toutes les distributions 64 bits (x86_64), rien à installer.


1. LE PLUS SIMPLE

   Double-cliquer « autorun.sh » à la racine de la clé : un terminal s'ouvre avec le menu.
   GNOME le propose aussi au branchement de la clé (« Lancer le logiciel ? »).


2. DANS UN TERMINAL

   Ouvrir un terminal (Ctrl+Alt+T sur la plupart des bureaux) et taper le chemin du programme, sans
   aller d'abord dans la clé avec « cd » : sur un autre ordinateur, Vanguard remonte la clé en lecture
   seule pour la protéger, ce qui échoue si un terminal y est ouvert.

     /run/media/$USER/VANGUARD/Linux/vanguard     Arch, Fedora, openSUSE, Manjaro…
     /media/$USER/VANGUARD/Linux/vanguard         Ubuntu, Debian, Mint, Pop!_OS…

   Où la clé est-elle branchée ?   lsblk -o LABEL,MOUNTPOINT | grep VANGUARD
   Astuce : taper le début du chemin, puis la touche Tab pour le compléter.


3. COMMANDES UTILES

   Sans rien après « vanguard » : le menu. Sinon (« vanguard » = le chemin complet ci-dessus) :

     vanguard bilan                bilan complet : cet ordinateur, puis le réseau
     vanguard bilan --texte        même bilan, rapport en texte simple (serveur sans écran)
     vanguard corriger             bilan, puis chaque correction montrée et confirmée
     vanguard audit                audit de cet ordinateur seulement
     vanguard appareils            scan du réseau local
     vanguard mises-a-jour         mises à jour : système, Flatpak, Snap, firmware…
     vanguard reparer              réparations : Internet, disque plein, mises à jour bloquées…
     vanguard nettoyer --liste     place à gagner, sans rien effacer
     vanguard test-connexion       test de connexion : ping, débit, bufferbloat
     vanguard antivirus <dossier>  analyser une clé, un disque ou un dossier
     vanguard --help               toutes les commandes (vanguard <commande> --help : le détail)
     vanguard --version            la version


4. BON À SAVOIR

   - Le terminal n'a pas besoin d'être lancé en root : une correction demande ton mot de passe (sudo) au
     moment où tu l'acceptes, jamais avant.
   - « Permission non accordée » : la clé est montée sans droit d'exécution (option noexec). Copier le
     programme puis le lancer :  cp /run/media/$USER/VANGUARD/Linux/vanguard ~/ && ~/vanguard
   - L'installer sur cet ordinateur : copier « vanguard » dans ~/.local/bin, puis taper simplement
     « vanguard » dans n'importe quel terminal.
   - En anglais :  VANGUARD_LANG=en /run/media/$USER/VANGUARD/Linux/vanguard
   - Quitter : q dans le menu, ou Ctrl+C.


5. INSTALLER LINUX DEPUIS LA CLÉ

   Démarrer l'ordinateur sur la clé (touche du menu de démarrage : F12, F11, F8 ou Échap selon le PC),
   puis choisir dans le menu de Ventoy. Debian, Fedora et Arch s'installent par Internet (câble ou Wi-Fi).
   - Omarchy : choisir « Omarchy » : son installateur règle tout (disque chiffré compris), sans Internet.
     À la main depuis Arch Linux (archinstall, puis « curl -fsSL https://omarchy.org/install | bash ») :
     https://learn.omacom.io/2/the-omarchy-manual/96/manual-installation
   - Les images se mettent à jour toutes seules (Ventoy aussi, après accord) quand la clé est branchée sur
     l'ordinateur qui la prépare, et chaque jour si elle y reste branchée.
